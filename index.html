Exercise 1 ⏱️ 20 minutes Intermediate

Adaptive Web Scraping

Build a resilient web scraper that automatically adapts when website structures change, using multiple selector strategies.

Learning Objectives

  • Implement multiple selector strategies (ID, class, structural)
  • Handle HTML changes gracefully with fallback mechanisms
  • Validate scraped data for completeness
  • Test against three different HTML versions

Your Tasks

  1. Open exercises/exercise_01_scraping.py
  2. Implement the AdaptiveScraper class with multiple selector strategies
  3. Add data validation to ensure all required fields are present
  4. Test against v1.html (should use ID selectors)
  5. Test against v2.html (should fall back to class selectors)
  6. Test against v3.html (should use structural selectors)

Key Concepts

CSS Selectors Fallback Strategies Data Validation Error Handling

Detailed Instructions

Step 1: Understanding the Problem

Websites change their HTML structure frequently. Your scraper needs to handle these changes without breaking.

Step 2: Selector Hierarchy

  • Primary: ID selectors (most specific, e.g., #gdp-value)
  • Secondary: Class selectors (e.g., .metric-value[data-metric="gdp"])
  • Tertiary: Structural selectors (e.g., table tr:nth-child(1) td:nth-child(2))

Step 3: Implementation Pattern

for strategy in self.strategies:
    try:
        data = strategy.extract(soup)
        if self.validate(data):
            return data
    except Exception:
        continue
raise ValueError("All strategies failed")

💡 Hints

Hint 1: Use BeautifulSoup's select_one() method for CSS selectors
Hint 2: Store strategies in a list and iterate through them
Hint 3: Validation should check that all required fields have non-empty values
